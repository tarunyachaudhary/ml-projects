# Movie Recommendation System

A content-based movie recommendation system built using Python
and machine learning.

## Features

- Content-based movie recommendations
- Movie similarity using cosine similarity
- Text vectorization using CountVectorizer
- NLP preprocessing and stemming
- Streamlit web application

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- NLTK
- Streamlit

## Dataset

TMDB 5000 Movie Dataset.

## How to Run

Install dependencies from this directory:

```bash
pip install -r requirements.txt
```

Run the `notebooks/movies_recommendation_system.ipynb` notebook to generate the model artifacts, then start the application:

```bash
streamlit run app.py
